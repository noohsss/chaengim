# 챙김 미니 브랜드 시스템

> 기준 방향: Soft Horizon  
> 기준 이미지: [`assets/soft-horizon-reference.png`](./assets/soft-horizon-reference.png)  
> 범위: 브랜드 기초, 로고, 색상, 타이포그래피, 아이콘, 문체

## 1. 브랜드 성격

챙김은 복잡한 정책 정보를 따뜻하게 정리하고 다음 행동을 분명하게 안내한다.
공공 정보의 신뢰성을 유지하되 관공서처럼 무겁거나 권위적으로 보이지 않는다.

- 따뜻한 신뢰: 친근하지만 가볍거나 장난스럽지 않다.
- 차분한 낙관: 과장 없이 사용자가 다음 단계를 찾도록 돕는다.
- 명확한 안내: 짧은 문장과 구체적인 동사로 행동을 제안한다.
- 충분한 여백: 정보량이 많아도 시각적으로 조급하지 않게 구성한다.

## 2. 로고

심볼은 손길, 북마크, 체크를 결합한다. 사용자가 필요한 혜택을 직접 챙겨
보관하고 완료한다는 의미다. 워드마크는 Pretendard Variable SemiBold로
표현하며 심볼과 실제 텍스트를 함께 사용한다.

### 제공 자산

- `public/brand/brand-symbol-primary.png`: 코른플라워 블루 심볼
- `public/brand/brand-symbol-monochrome.png`: 단색 심볼
- `src/app/icon.png`: 512px 애플리케이션 아이콘

### 사용 규칙

- 기본 락업은 심볼과 `챙김` 워드마크를 함께 사용한다.
- 32px 이하에서는 심볼만 사용한다.
- 최소 여백은 심볼 내부 체크 획 두께의 2배 이상 확보한다.
- 심볼 비율, 획, 색상, 각도는 임의로 변경하지 않는다.
- 그라데이션, 외곽선, 그림자, 국가 상징이나 관공서 문양을 추가하지 않는다.
- 복잡한 사진이나 대비가 낮은 배경 위에 직접 올리지 않는다.

## 3. 색상

### 브랜드 팔레트

| 토큰 | 값 | 용도 |
|---|---|---|
| `--brand-sky` | `#E6F2FF` | 넓은 브랜드 배경, 선택 영역 |
| `--brand-cornflower` | `#4E8AF7` | 로고, 장식, 큰 아이콘 |
| `--brand-off-white` | `#FAFAF7` | 기본 페이지 배경 |
| `--brand-mint` | `#DFF3EC` | 긍정·완료 보조 배경 |
| `--brand-light-gray` | `#ECEFF3` | 비활성·보조 표면 |

`#4E8AF7`은 흰색 위 작은 텍스트 대비가 충분하지 않으므로 본문 링크나
버튼 배경에는 사용하지 않는다. 인터랙션에는 다음 접근성 변형을 쓴다.

| 의미 토큰 | 값 | 용도 |
|---|---|---|
| `--primary` | `#2563D8` | 기본 버튼과 링크 |
| `--primary-hover` | `#1D5CCB` | hover |
| `--primary-pressed` | `#164FAF` | active |
| `--foreground` | `#252A33` | 기본 본문 |
| `--muted-foreground` | `#5D6675` | 보조 본문 |
| `--destructive` | `#C7353F` | 오류와 마감 임박 |
| `--ring` | `#2563D8` | 키보드 포커스 |

## 4. 타이포그래피

Pretendard Variable을 자체 번들링한다. 외부 CDN은 사용하지 않는다.

| 역할 | 크기 / 행간 | 굵기 |
|---|---|---|
| Heading | `22px / 28px` | Medium 500 |
| Body 1 | `16px / 24px` | Regular 400 |
| Body 2 | `14px / 20px` | Regular 400 |
| Caption | `12px / 16px` | Regular 400 |

- 한글 제목은 자간을 `-0.025em` 안에서만 조정한다.
- 긴 본문은 한 줄 65자 이내를 권장한다.
- 중요한 정보는 굵기와 간격으로 구분하고 불필요한 색상 추가를 피한다.

Pretendard는 SIL Open Font License 1.1로 배포된다. 라이선스 전문은 설치된
`pretendard` 패키지와 [공식 저장소](https://github.com/orioncactus/pretendard/blob/main/LICENSE)에서 확인한다.

## 5. 아이콘과 형태

- Lucide 아이콘을 사용하고 기본 크기는 20px 또는 24px다.
- stroke width는 2px, line cap과 join은 round를 유지한다.
- 아이콘만으로 의미가 불명확하면 텍스트 레이블을 함께 제공한다.
- 장식용 아이콘은 접근성 트리에서 숨긴다.
- 기본 radius는 12px, 입력·버튼은 10px를 사용한다.
- 4px를 기본 간격 단위로 사용한다.

## 6. 문체

- 사용자의 행동을 직접 설명한다: `챙기기`, `조건 확인하기`, `다음 단계 보기`.
- 자격이나 수급 가능성을 확정하지 않는다: `신청할 수 있어요`보다
  `신청 조건을 확인해 보세요`를 사용한다.
- 행정 용어는 가능한 한 쉬운 말로 바꾸고 원문 용어가 필요하면 함께 적는다.
- 오류는 책임을 사용자에게 돌리지 않고 해결 방법을 한 문장으로 제시한다.

## 7. 접근성

- 일반 텍스트는 WCAG AA 4.5:1, 큰 텍스트와 UI 경계는 3:1 이상을 유지한다.
- 모든 키보드 조작 요소에 3px 포커스 링과 3px offset을 제공한다.
- 모바일 터치 대상은 최소 44px를 확보한다.
- 색상만으로 상태를 전달하지 않고 아이콘이나 텍스트를 함께 제공한다.
- 라이트 모드만 지원한다. 다크 모드는 별도 검증 후 추가한다.
